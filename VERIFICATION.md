# Phase 0 verification (checked 2026-10-21)

| # | Claim | Result | Source |
|---|---|---|---|
| 1 | free-exercise-db is under the Unlicense | **Confirmed.** The file is `LICENSE.md`, not `LICENSE` (`/LICENSE` returns 404). It reads "This is free and unencumbered software released into the public domain." The GitHub API reports `spdx_id: Unlicense`. apis.io says "The whole dataset is released under the Unlicense." | https://github.com/yuhonas/free-exercise-db/blob/main/LICENSE.md, https://apis.io/providers/free-exercise-db/ |
| 2 | `primaryMuscles`, `equipment`, `instructions`, `images`, `level` exist | **Confirmed.** All 876 records have all five, plus `id`, `name`, `force`, `mechanic`, `secondaryMuscles`, `category`. The chest value is spelled exactly `chest` (lowercase), and 84 exercises have it as a primary muscle. **Caveat:** `equipment` is `null` on 77 records (`force` on 30, `mechanic` on 87). | https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/dist/exercises.json |
| 2a | All `primaryMuscles` values | abdominals, abductors, adductors, biceps, calves, chest, forearms, glutes, hamstrings, lats, lower back, middle back, neck, quadriceps, shoulders, traps, triceps | same |
| 3 | Image paths are relative to `…/main/exercises/` | **Confirmed** by the README. `3_4_Sit-Up/0.jpg` and `Barbell_Bench_Press_-_Medium_Grip/0.jpg` return HTTP 200 `image/jpeg` with `access-control-allow-origin: *`. | https://github.com/yuhonas/free-exercise-db |
| 4 | YouTube embed rules apply only to embedded players | **Confirmed.** The page covers "API Clients" and the embedded player (Referer header, no overlays, no autoplay until visible) and says nothing about plain links. A search link returned HTTP 200 and opened in a headless browser. | https://developers.google.com/youtube/terms/required-minimum-functionality |
| 5 | PWA install requirements | **Confirmed, with a correction.** You need HTTPS (or localhost) and a manifest with `name`/`short_name`, 192px and 512px icons, `start_url`, and `display`/`display_override`. Chromium also requires `prefer_related_applications` to be absent or false. **MDN says a service worker is *not* required for installability.** It is only needed for offline use, so the app ships one anyway. | https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable |
| 6 | GitHub Pages: 1 GB site, soft 100 GB/month bandwidth | **Confirmed.** | https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits |
| 6a | Private repos need a paid plan | **Not confirmed.** Neither the limits page nor "What is GitHub Pages" says this. Irrelevant here because the repo is public. | — |
| K1 | iOS deletes script-written storage after 7 days without interaction; Home Screen apps are exempt | **Confirmed.** The cap also covers **LocalStorage**, which this app uses. | https://webkit.org/tracking-prevention/ |
| K2 | `navigator.storage.persist()` does not override the 7-day rule | **Not independently checked.** The WebKit page lists no exception for it. The secondary source (GitHub issue) was not fetched. | — |
